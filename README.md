# Sentinel Trinity — SIH26163

Security Assessment of the World Monitor Application
**Organization:** NTRO · **Category:** Software · **Theme:** Smart Automation

Sentinel Trinity is an evidence-first cybersecurity assessment platform for
authorized local/staging deployments of the World Monitor application. It is
**local-first and safe by design** — all findings, evidence, and events in
this build are mock/simulated demo data for an authorized local lab target
(`http://localhost:3000`). No production scanning is performed.

## Product Modules
1. AI Trust Firewall — content scanning, prompt-injection detection, quarantine queue
2. Protocol Safety Shield — payload validation, contract drift, threat analytics
3. Desktop Trust Guard — IPC command inventory, trust boundary, policy actions
4. TrustLens Evidence & Remediation — Findings, Evidence Vault, Fix Validation, Reports

## Tech Stack
- Django 4.2 (Python 3.10+)
- SQLite (bundled, zero setup)
- Server-rendered templates, no frontend build step required
- Vanilla CSS/JS (dark glass UI, animated gauges/sparklines)

## How to Install & Run

```bash
# 1. Create and activate a virtual environment (recommended)
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run migrations
python manage.py migrate

# 4. Seed realistic demo data (findings, evidence, IPC commands, quarantine, certificates)
python manage.py seed_data

# 5. (Optional) create an admin user to browse data at /admin/
python manage.py createsuperuser

# 6. Run the dev server
python manage.py runserver
```

Then open **http://127.0.0.1:8000/** in your browser.

To re-seed data at any point (resets all demo records):
```bash
python manage.py seed_data
```

## Demo Data
All findings (WM-AI-002, WM-PROTO-003, etc.), evidence items, IPC commands,
quarantine entries, security events, and proof-of-fix certificates are
synthetic and generated by `seed_data.py`. Nothing in this build connects to
a real network target, real credentials, or a real World Monitor instance.

## Pages Included
Overview · Attack Surface · AI Trust Firewall · Protocol Safety Shield ·
Desktop Trust Guard · Findings (list + detail with real actions) ·
Evidence Vault · Fix Validation (generates real Proof-of-Fix certificates) ·
Security Reports · Settings

## Safety Disclaimer
"Authorized Local Environment Only." Production scanning is disabled.
All demonstrations use synthetic data and controlled local test cases.
No destructive, denial-of-service, credential, or production testing is
performed. AI analysis is advisory; human validation is required.
